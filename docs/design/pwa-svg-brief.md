# PWA用SVG素材の制作仕様

2026-10-05。C案の紙のパスポートに合わせ、橋を軸に細い輪郭と余白を使う。既存のTrussロゴは維持する。素材が揃うまで、既存ロゴ・Font Awesome・神戸の水彩で画面を成立させる。

## 先に用意する候補

| 素材 | 構成 | 使用予定 | 推奨viewBox |
| --- | --- | --- | --- |
| `passport-bridge-mark.svg` | 橋を小さく簡略化した単色マーク。文字・背景なし | 会員証、参加チケットのブランドアクセント | `0 0 64 64` |
| `attendance-stamp.svg` | 橋を中心にした円形または角丸の出席印。日付・イベント名・文字なし | 出席記録の導入時。日時・名称はアプリのテキストとして重ねる | `0 0 128 128` |

橋マークは24〜32pxでも読める太さ、出席印は48〜64pxでも輪郭が残る形にする。硬い幾何学だけにせず、輪郭を少し柔らかくしてよい。紙の汚れや細かい掠れは小サイズで潰れるため抑える。

## 共通仕様

- 透過背景、正方形のviewBox。図形の外側に約8%の余白。
- 基本は単色 `currentColor`。確認用の色はNavy `#3D4756`。必要ならブランドBlue `#6DB9E7`の2色版を別ファイルにする。
- テキスト・フォント参照・外部画像・埋め込みPNG・スクリプトは含めない。文字はアプリ側で日英を切り替える。
- SVGの可視部分はパスまたは基本図形。固定pxのwidth/heightに依存しない。
- 原本の編集可能なファイルも保管する。納品候補は `docs/design/source/`、採用した配信用SVGは `apps/web/public/images/` に配置する。
- 出席印は将来の記録表示に用いる素材であり、今回は出席履歴やスタンプ機能を有効化しない。

## 後から追加する候補

部活が実際に発足した段階で、同じ輪郭・余白・色の小さな紋章を揃える。グルメ／朝活／ランニング／コーヒー／カラオケ／おにぎり／パンの7点が候補。部活の所属表示と、イベントの操作用アイコンは分ける。初期はFont Awesomeと文字で表示できるので、全7点の制作は着手条件にしない。

チケット全体、QR、カメラ・地図・写真追加などの操作アイコン、活動写真は個別のSVG制作を依頼しない。チケットの文字や状態はCSSとHTMLで組み、QRの読み取り領域へ装飾を重ねない。
